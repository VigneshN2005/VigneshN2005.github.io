job-search-agent-teal-tau.vercel.app
Live2026

Conversational Job-Search Agent

Scout is a chat agent that finds real jobs from a plain-words description, remembers what you told it, and only recommends postings it actually found.

  • The LLM calls tools (search_jobs, filter_jobs, save_preference) and keeps session memory in PostgreSQL.
  • 670+ real tech postings, refreshed daily, stored with pgvector embeddings. Search mixes vector similarity with SQL filters, then re-ranks by keywords, saved preferences and freshness.
  • Answers are JSON validated with Pydantic, and any pick a tool didn't return is dropped. On a 20-case eval, every completed case passed with 0 made-up jobs.
  • Shipped through its own CI/CD: lint, 53 tests, Gitleaks and pip-audit, Docker build with Trivy scan, then deploy to Vercel and a health check.

ARIA · River Encroachment Analyst

Detects illegal encroachment on rivers, forests and wetlands around Bengaluru, using 30 years of Landsat and Sentinel imagery over about 4,000 sq km.
